# 原声索引 · Lossless Atlas

> 社区共建的无损音乐指南，发现好音乐，查找好版本。

一张专辑，可能有不同的发行版本、母带处理和获取渠道。原声索引希望把这些信息整理在一起，让喜欢音乐的人少一些反复搜索，多一些安心聆听。

在这里，你可以分享值得听的专辑、补充可核验的版本资料、推荐官方无损入口，也可以帮助修正错误和失效链接。无论设备和经验如何，只要愿意认真听、认真分享，都欢迎参与。

**项目正在起步，首批专辑待收录。欢迎提交你的第一份推荐。**

## 我们整理什么

| 内容 | 你能找到的信息 |
| --- | --- |
| 专辑推荐 | 推荐理由、音乐风格、值得关注的曲目 |
| 发行版本 | 发行年份、厂牌、地区、目录编号及版本差异 |
| 无损入口 | 艺术家、厂牌及正版平台的试听、购买或授权下载页面 |
| 聆听记录 | 有具体依据的版本比较，以及明确标注的个人听感 |
| 授权作品 | 创作者明确允许分享的录音及对应许可说明 |

我们重视音乐本身，也重视信息是否准确。收录不以文件大小、采样率或器材价格作为排名依据。

### 条目信息

每条推荐尽量包含以下信息。无法确认的字段请写“待核验”，不要猜测。

| 字段 | 说明 |
| --- | --- |
| 艺术家／专辑 | 使用正式名称，可补充常见译名 |
| 年份／风格 | 区分作品首发年份与所推荐版本的发行年份 |
| 推荐理由 | 说明音乐、演奏、录音或制作上值得关注的地方 |
| 版本信息 | 厂牌、发行地区、目录编号、原版或重制版等 |
| 音频规格 | 按来源页面记录格式、位深、采样率和声道；未注明则如实标注 |
| 来源入口 | 优先提供具体专辑页面，而非平台首页或搜索结果 |
| 获取方式 | 购买下载、订阅播放、免费授权下载等 |
| 可用范围 | 已知的地区、账户或订阅要求 |
| 核验信息 | 资料依据、核验日期及仍有疑问的部分 |

## 收录标准

1. **来源可追溯。** 提供艺术家、厂牌、发行商或正版平台页面；版本资料尽量附可核验的出处。
2. **推荐有内容。** 写清楚为什么值得听，避免只有“神专”“顶级音质”等结论。
3. **版本说清楚。** 不把不同发行版、混音版或重制版混为一谈；同一专辑可补充多个版本。
4. **事实和听感分开。** 参数、发行信息应有依据；个人感受请标明试听版本及必要的比较条件。
5. **未知如实标注。** 不凭扩展名、文件体积或频谱截图就宣称“原生高解析”“绝无转码”。
6. **入口明确有效。** 说明获取方式和已知限制；不使用短链、推广返佣链接或需要私信才能获取的入口。

维护者会检查资料完整性、来源和链接。**收录表示条目符合整理要求，不代表项目已对录音、母带或所有文件进行独立鉴定。**

## 如何参与

### 通过 Issue 推荐

不熟悉 Git 也可以参与：

1. 先在仓库和已有 Issue 中搜索艺术家及专辑名，避免重复。
2. [新建 Issue](https://github.com/Adobiz/lossless-atlas/issues/new)，标题建议使用 `[推荐] 艺术家 — 专辑名`。
3. 复制下方模板，补充推荐理由和来源。
4. 维护者核验后整理收录；需要补充的信息会在 Issue 中沟通。

纠错可以使用 `[纠错] 条目名称`，失效链接可以使用 `[失效链接] 条目名称`。

### 通过 Pull Request 贡献

1. Fork 本仓库，并在自己的分支上修改 README。
2. 在对应分类下补充条目，或修正已有信息。
3. 提交 Pull Request，说明新增或修改了什么，并附资料依据。
4. 等待审核后合并。

欢迎小而完整的贡献：补充一个版本编号、修正一处年份、替换一条失效链接，都能让索引更可靠。

```markdown
- **获取方式**：购买下载／订阅播放／免费授权下载
- **地区或账户限制**：
- **资料来源**：
- **最后核验日期**：YYYY-MM-DD

**为什么推荐**
用几句话说明值得听的地方，可列出一至三首推荐曲目。

**版本说明与个人听感（可选）**
说明比较了哪些具体版本，区分可核验的信息与主观感受。

```

## 关于无损与版本

- **无损描述的是编码方式。** FLAC、ALAC 等格式可以无损保存音频数据，但格式本身不能证明音频的原始来源。
- **参数更高，不自动等于更好听。** 录音、混音、母带处理和播放条件都会影响听感。
- **同名专辑可能有多个版本。** 比较时应尽量确认具体发行版，避免把母带差异归因于文件格式。
- **重制版是否更好，需要具体比较。** 欢迎描述差异，不把个人偏好写成统一结论。
- **试听入口不一定提供无损播放。** 试听用途与购买、下载或订阅后的音质规格应分别说明。

## 来源与授权

本项目主要整理音乐资料与来源链接。商业作品优先链接到艺术家、厂牌或正版平台的具体页面。

如分享可再分发的音频，必须附上明确授权依据，并遵守署名、用途及其他许可条件。不收录未经授权的商业录音副本、付费资源搬运、破解内容或绕过访问限制的获取方法；这项要求同样适用于外部链接。

专辑名称、封面、音乐及引用资料的权利归各自权利人所有。本仓库的公开可访问性不代表其中提及的音乐可以自由转载或再分发；各项内容以其具体授权为准。

如果发现来源、授权或内容存在问题，请[提交反馈](https://github.com/Adobiz/lossless-atlas/issues/new)，附上条目位置和可核验的依据。请勿在公开 Issue 中填写个人敏感信息。

如果这个索引帮你找到了一张喜欢的专辑，欢迎留下 Star，也欢迎把下一张好专辑带来。

**让好音乐被发现，让好版本有迹可循。**
